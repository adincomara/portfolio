# Adin Comara — Personal Portfolio Website

Personal developer portfolio website of **Adin Comara**, Full-Stack Laravel & AI Engineer.

## 🚀 Features
- **Clean & High-Tech Design**: Light/Dark mode toggle (default light), modern tech-grid aesthetics, and smooth spring reveal animations.
- **Showcase & Tech Stack**: Highlights core competencies in Laravel backend architecture, RESTful API design, database optimization, and Applied Multimodal AI (Vision OCR, LLM agents).
- **Responsive**: Mobile-first, looks great across smartphones, tablets, and desktop browsers.
- **Fast & Dependency-Free**: Pure HTML, Tailwind CSS (via CDN), and vanilla JavaScript.

## 📂 Project Structure
- `index.html`: Main portfolio page with theme toggle and interactive reveal animations.
- `profile.jpg`: Circular profile photo with ambient glowing aura.

## 💻 Running Locally
```bash
python3 -m http.server 8088
```
Open `http://localhost:8088` in your browser.
